# Reach Academy — Sitio Web Oficial

Plataforma web académica y profesional diseñada para **Reach Academy** (Barquisimeto, Venezuela), orientada a la preparación académica internacional, preparación para exámenes estandarizados (TOEFL, SAT, DET), tutorías STEM y admisiones universitarias.

## 🚀 Demo en Vivo
Puedes ver el sitio publicado en: [https://dinagvf.github.io/reach-academy-web/](https://dinagvf.github.io/reach-academy-web/)

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura semántica.
* **CSS3 & Bootstrap 5:** Diseños responsivos y estilos personalizados (fuentes Cinzel e Inter).
* **JavaScript (Vanilla):** Renderizado dinámico de oferta académica y filtrado por pestañas.
* **WhatsApp API:** Integración directa para solicitudes de nivelación y pre-inscripción.
